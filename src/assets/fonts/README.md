# Clash Grotesk Font Files

Please add the following Clash Grotesk font files to this directory:

- ClashGrotesk-Regular.woff2
- ClashGrotesk-Medium.woff2
- ClashGrotesk-Semibold.woff2
- ClashGrotesk-Bold.woff2

## Where to get Clash Grotesk

Clash Grotesk can be obtained from:
- [Indian Type Foundry](https://www.indiantypefoundry.com/) (Official)
- [FontShare](https://www.fontshare.com/fonts/clash-grotesk) (Free alternative)

## Font Format

Make sure to use WOFF2 format for optimal web performance and compression.
